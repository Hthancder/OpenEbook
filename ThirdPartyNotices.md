The complete resolved dependency list is generated by Swift Package Manager during Xcode project resolution. It is the artifact needed for an accurate redistribution audit; transitive package and embedded-resource license texts have not yet been inventoried or bundled. The iOS workflow uploads the resolved package file alongside the unsigned IPA so that audit can follow an actual resolver run rather than guessed dependency counts.

## Application-maintained Readium patch

The build prepares Readium 3.11.1 at upstream commit `9a8c094b72245fd27043c9d298005e5c78b32a01` and applies `Scripts/Patches/readium-3.11.1-offline.patch`. This is a local security adjustment, not an upstream release. It installs an opt-in offline policy before initial WebKit loads. The original BSD-3-Clause terms are preserved in `Scripts/Patches/Readium-LICENSE.txt` and the bundled `BookReader/Resources/ThirdPartyNotices.md`. The patch does not establish runtime network isolation until the hostile navigator probe passes.
